# 混元 4 · 改动台账（两边对上游 / 原版的每一处改动）

这张表记两边的**每一处**改动，对照的是上游或原版：MaxText 对上游 `AI-Hypercomputer/maxtext`，Megatron-Core / Megatron-Bridge 对原版发布。每处一行，改了就当场加一行或改状态，不另起表。

  - 模型结构上的缺口：GPU 照 MaxText 补。
  - 优化器与 loss 的细节：MaxText 加默认关的开关去对上原版 Megatron-Core，GPU 保持原版。
- 协议见 [`PROTOCOL.md`](PROTOCOL.md)，各开关的开 / 关语义见 [`alignments/01-mini/config-alignment.md`](alignments/01-mini/config-alignment.md)。

列的含义：
- **哪一侧**：MaxText（`maxtext`，混元 4 集成分支（2026-11-07 18:52 起；分支名带个人账号，按仓库规矩不写进来；建于 `d723fa2d`，含混元 4 移植分支（分支名同样带个人账号）、`feat/68-hy4-numerics-alignment` 的精度开关与 `feat/68-hy4-reverse` 上的全部改动，后者停用））、Megatron-Core、Megatron-Bridge、janus（本仓库的 GPU / TPU 程序与工具）。
- **对齐到谁**：这处改动让哪一侧的语义成为标准，或者是修 bug。
- **开关 / 默认**：没有开关的写「无」；有开关的写名字和默认值，以及 T1 取的值。
- **数值核验**：怎么核的、结果。
