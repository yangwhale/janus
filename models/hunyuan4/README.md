# 混元 4

混元 4 从 GPU（B200 × 8，Megatron-Core）迁到 TPU（v5p，MaxText）训练，这里检查两边训出来的数值是否一致。

主线是 **hy4-mini**：混元 4 的全部结构、缩小宽度和层数的随机初始化模型。

**现状：还不能签字**（签字＝正式宣布两边对齐了）。hy4-mini 训练 1000 步的 9 项曲线没有一项不过：7 项对上，梯度范数、路由偏置标准差 2 项略超出 GPU 自己重跑的波动，查明原因后已接受；另一份运行的最大注意力打分前 300 步略超，也已接受。挡签字的还有四件事，见[对齐报告](alignments/01-mini/ALIGNMENT-REPORT.md#挡签字的四件事)。项目的验收对象是真实权重截层（只取混元 4 真实权重的前几层组成的小模型），那边的签字条件一条都还没满足。
