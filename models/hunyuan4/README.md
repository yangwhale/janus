# 混元 4

混元 4 从 GPU（B200 × 8，Megatron-Core）迁到 TPU（v5p，MaxText）训练，这里检查两边训出来的数值是否一致。

主线是 **hy4-mini**：混元 4 的全部结构、缩小宽度和层数的随机初始化模型。

**现状：还不能签字**（签字＝正式宣布两边对齐了）。以现行比较 tz-off-rep 为准（2026-11-11 起对齐配置关 base2，1000 步噪声用 GPU 16 份）：hy4-mini 训练 1000 步的 9 项曲线没有一项不过：7 项对上，主 loss 全程与第 101 步起 2 项略超出 GPU 自己重跑的波动（1.55、1.52 倍），后段根因还在查；梯度范数、路由偏置标准差已对上。同一运行前 300 步的梯度范数、另一份同配置运行（`tz-off-qkq`）的最大注意力打分也略超，这两项在 base2 开时已接受，关 base2 后没有重做同一状态的证据，状态待定（base2 开时的接受是否沿用尚未决定）。挡签字的事见[对齐报告](alignments/01-mini/ALIGNMENT-REPORT.md#挡签字)。项目的验收对象是真实权重截层（只取混元 4 真实权重的前几层组成的小模型），那边的签字条件一条都还没满足。
