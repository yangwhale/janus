# 混元 4 · 对不齐的根源与修复一览

一行一个对不齐的根源（一个机制、一个修法），各尺寸共用；数多数来自 hy4-mini，出处在最后一栏，开关细节在 [`CHANGES-LEDGER.md`](CHANGES-LEDGER.md)，证据在 [`cases/`](cases/README.md)，「第 n 类」指[精度边界](../../docs/reference/precision-boundaries.md)的类别。别处说「根源一览第 n 行」指 # 列。完整读法见[总览细节「读法」](dashboard/detail.md#读法)，术语见[知识库的术语对照表](knowledge.md#术语对照表)。

| 术语 | 含义 | 判定线 |
|---|---|---|
| N | 噪声上限：GPU 同设置重跑之间的差（L4：8 份两两 28 对里这个量的最大值；L3：第 1 步三份两两的最大 rel_L2） | — |
| r | TPU 对 GPU 的差 ÷ N，不定责 | ≤ 1 过，> 2 不过 |
| R | rel_L2(TPU, CPU FP64) ÷ rel_L2(GPU, CPU FP64)，能定责 | ≤ 1.2 过 |
| 带符号均值 / MARE / 最大单步 | L4 的三个判定量：逐步相对差的平均（带符号）、逐步相对差绝对值的平均（MARE）、单步最大的相对差；r 取三者里最差的 | 各自对 N 判 |
| 定责 | 查明一个差别来自哪边、为什么 | — |
| 定责依据 | 对 CPU FP64 的 R；读代码对照语义标准；只改一边后两边的差收拢 | 三种之一 |
| 类别 | A 对齐专用；B 修 bug 或更准、生产也开（代价 < 1%）；C 取舍（代价 ≥ 1%）；设置。生产看对真值的误差加代价，对齐看是否照 GPU，两者可以不同 | — |
| 代价 | hy4-mini 300 步单开关 A/B：全开步时 0.4767 s ÷ 只关该开关的步时 − 1 | — |
| 「T1 开」 | mini 对齐配置里打开（T2 = 真实权重截层，mid 同理） | — |

修前 → 修后写作「量（窗口）：N 或 GPU，TPU（或两边的差），比值」。
