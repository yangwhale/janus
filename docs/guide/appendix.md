# 附录

指南各章讲怎么做。查用的材料放在下表这几处：

| 要查 | 在哪 |
|---|---|
| 名词 | [术语表 `glossary.md`](../glossary.md) |
| 判法为什么这样定、指标定义、检查规格、文件格式、命令行 | [`docs/reference/`](../README.md#reference参考)（列表在文档索引） |
| 混元 3 的全部材料：对齐报告、检查清单、golden 出处、配置对照、各实践结果、两边操作手册 | [`models/hunyuan3/README.md`](../../models/hunyuan3/README.md) |
| 改 janus 本身：架构、约定、仓库布局、设计文档、路径变更 | [`docs/dev/`](../dev/README.md)、[`CONTRIBUTING.md`](../../CONTRIBUTING.md) |
| 工具版本 | [`CHANGELOG.md`](../../CHANGELOG.md)：判法改了的条目前标 **[判定]**，并写明已提交的结果受不受影响 |

最常查的几处：

- 指标从定义到 r 的入门讲解与算例：[专题《尺子》](ruler.md)。
- 每个指标的分子、分母、窗口、噪声上限与边界情况：[`reference/metrics.md`](../reference/metrics.md)。
- 噪声参照、1 倍 / 2 倍、两档门槛：[`reference/judging.md`](../reference/judging.md)。
- 每级查什么、准出、不过时先查什么：[`reference/levels.md`](../reference/levels.md)。
- 混元 3 每项检查比什么、结果如何：[检查清单 `CHECKS.md`](../../models/hunyuan3/CHECKS.md)；跨实践总览：[`dashboard.md`](../../models/hunyuan3/dashboard/dashboard.md)。
