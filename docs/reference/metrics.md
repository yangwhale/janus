# 指标：怎么算

这一页写每个指标的分子、分母、窗口、边界情况，噪声上限怎么从参照对算出来，以及混元 3 上的实测量级。

第一次读，先看入门讲解[《尺子》](../guide/ruler.md)：每个指标从定义到 r 走一遍，带混元 4 的算例。为什么要这个指标、它看不见什么、判定为什么是 1 倍和 2 倍，见 [`judging.md`](judging.md)。每条检查用了哪个指标、门槛是多少、结果如何，见[混元 3 检查清单](../../models/hunyuan3/CHECKS.md)。实现在 [`janus/metrics.py`](../../janus/metrics.py)。

记号：a 是被测，b 是参照。参照一般是基线 golden，日常回归里是 [LKG](../glossary.md#lkg)。

## 共同规则

1. 拿谁跟谁比：被测与参照同一步、同名的量（例：两边第 1 步的 `layers.2.attn.out`）。被测的步号先按 `meta.steps.convention` 换成参照的步号。
2. 精度：除 ULP 外全部在 FP64 里算。相近的两个数相减本身是精确的，丢精度的是后面的平方和、点积和除法；在 FP32 里算，指标自己的误差会和要测的差一样大。
3. 非有限值先查：两边 NaN / +Inf / −Inf 的位置与取值必须一致，否则检查判 `fail`；一致时这些位置不参与计算。
4. 一条检查怎么出结论：一条检查常选中一批张量或几条序列，检查项目录里列出的每个指标各取这批里最差的那个、各自去判，最差的指标决定结果。

## 逐步序列：loss、grad_norm、param_norm

### 逐步统计量

| 量 | 怎么算 |
|---|---|
| 逐步相对差 dₜ | dₜ = (aₜ − bₜ) / 分母，带符号。分母默认 \|bₜ\|；可选被测 \|aₜ\|（`denominator: test`）或两边均值 \|aₜ + bₜ\| / 2（`denominator: mean`） |
| 窗口 `"s:e"` | 第 s 步到第 e − 1 步（左闭右开）。混元 3 的 `L4.loss` 是 `"1:1001"`，`L4.loss.tail` 是 `"301:1001"` |
| 首步差 d₀ | 首步（`meta.steps.first`，混元 3 是第 1 步）的 dₜ。只报，不进噪声判定 |
| 带符号均值 | 窗口内去掉首步后 dₜ 的算术平均。`"1:1001"` 时 n = 999 |
| MARE | 同一批步上 \|dₜ\| 的平均 |
| 最大单步 | 同一批步上 max\|dₜ\|，另报步号 |
| 标准误（只提示） | 带符号均值的标准误，取两种估计的较大者（见下） |
| 非有限值 | 窗口内任一步出现 NaN / Inf，检查判 `fail`；那几步列在 `nonfinite_steps`，窗口外的步不查 |

- 分母：grad_norm 逐步涨落约 ±3%，以参照为分母时带符号均值有偏置，混元 3 第一层的 `L4.grad_norm` 用 `mean`（理由见 [`judging.md`](judging.md#两处测量口径被测与参照的量要一样准统计量要对称)）。loss、param_norm 用默认分母。混元 4 自 2026-11-10 起全部用默认分母，梯度范数也不例外（[`grad-norm-denominator-rejudge.md`](../../models/hunyuan4/results/grad-norm-denominator-rejudge.md)）。
- 首步差：GPU 重跑时第 1 步 loss 通常逐位相同、差为 0，当不了尺子。要判就在目录里写 `first_step_tol` 加 `first_step_source`；混元 3 的验收目录没写。
- 带符号均值：随机的差正负抵消，剩下的是固定方向的偏移。判定时取绝对值；结果里的 `signed_mean_max` 已经是绝对值，偏高还是偏低看明细 `details/<检查 id>.jsonl`。明细不随结果提交，本地跑一遍 `janus run` 就有。
- 标准误：① 一阶自相关 ρ（截到 [0, 0.99]）折算有效样本数 n_eff = max(n·(1−ρ)/(1+ρ), 1)，标准误 = 样本标准差（ddof = 1）÷ √n_eff；② n ≥ 100 时切成 20 段、每段 ⌊n/20⌋ 步（余数丢掉），标准误 = 段均值的标准差 ÷ √20。\|均值 ÷ 标准误\| 远大于 2 提示持续偏移，不参与判定：两条轨迹分叉以后 dₜ 不平稳，标准误会偏小。
- 窗口内缺步：报错，不静默跳过。

### 噪声上限 N

- 检查项目录 `runs.noise` 里的每一对运行 `[A, B]`，A 当被测、B 当参照，用同样的窗口、同样的分母、同样去掉首步，算出 \|带符号均值\|、MARE、最大单步。
- 每个量的 N = 所有对里的最大值。
- 窗口内逐步完全相同的参照对（同一条轨迹的重复）剔除，列在结果的 `noise_dropped`；剔除后不足 3 对，最多给待定。
- 写了 `signed_mean_se_k: k` 时，带符号均值的上限取 max(N, k × 各参照对标准误的最大值)，防止几对参照恰好都很小、上限过紧。混元 3 第一层的两条 loss 检查写了 k = 2，结果里 `threshold.noise.floor` 给出这个下限。
- 留一法：每一对用其余各对的上限去判，列在 `noise_loo`，只报。某一对明显大于 1，说明上限由它一条撑着。
- 只对一份基线比时，目录有两种写法，判定量相同：`golden` 只列基线一份、噪声对写进 `runs.noise`（混元 3 第一层 `rcc`）；或列多份并写 `params.baseline: <名>`（第二层 `rc`）。列了多份 golden 却不写 `baseline` 时，janus 默认取对各份里最差的一份，和比较协议（[`judging.md`](judging.md#golden-怎么用几份只造噪声带比较只对一份)）不一样。

### 判定

- 三个量各算 r = 被测值 ÷ N，各自按「≤ 1 过、> 2 不过、之间待定」判，最差的决定结果。
- 结果里 `r2` 是带符号均值的比值，`r1` 是 MARE 的比值；最大单步的 r 用 `metrics` 里的最大单步除以 `threshold.noise.upper.max_step`。

### 例：v5p 当前配置的 `L4.loss`

被测 `t-rmap-on-1000` 对最终 golden 的基线 `rcc-a`，窗口 `"1:1001"`，出自 `phase2-acceptance-rcc-on.results.json`：

| 量 | 被测对 `rcc-a` | N（`rcc-a..j` 10 份两两 45 对的最大值） | r |
|---|---|---|---|
| \|带符号均值\| | 3.85e-5 | 9.47e-5 | 0.41（`r2`） |
| MARE | 1.10e-4 | 1.38e-4 | 0.80（`r1`） |
| 最大单步 | 5.90e-4 | 9.75e-4 | 0.61 |

三个 r 都 ≤ 1，判过；最差的是 MARE 的 0.80，就是清单里这一格的值。

### 学习率

`scalar_series`：窗口内每一步（含首步）\|aₜ − bₜ\| ≤ rtol·\|bₜ\| + abs_ulp·ulp(bₜ)，任一步超就不过。默认容差 2 个 FP32 ULP；混元 3 验收设 rtol = 0、abs_ulp = 0，即逐步相等。

### GPU 重跑的实测量级

第一阶段 GPU 默认设置 100 步（`phase1-full` 的 `L4.loss`，窗口 1–100，噪声 3 对）：

| 量 | 实测 | 噪声上限 |
|---|---|---|
| d₀ | 0 | 不进噪声判定 |
| 带符号均值 | 2.87e-5 | 5.72e-5 |
| MARE | 3.94e-5 | 5.92e-5 |
| 最大单步 | 2.41e-4 | 2.27e-4（待定） |

## 张量：第 1 步的激活、梯度、状态

除 `kl` 外，每个张量拉直成一个向量，一个张量出一个数。`kl` 按最后一维分行算，再取行平均。

### 定义表

「实测量级」是第一阶段 GPU 默认设置两次运行之间、第 1 步的差（`phase1-full` 里 L2 / L3 检查的实测值或噪声上限）。

| 指标 | 怎么算 | 一批里取 | 边界 | 实测量级 |
|---|---|---|---|---|
| `rel_l2` | ‖a − b‖₂ / ‖b‖₂ | 最大 | b 全零：a 也全零给 0，否则 inf | 前向 0；参数梯度 ≤ 6.6e-4；激活梯度第 3 层 1e-5 到第 0 层 4.3e-3 |
| `cosine` | a·b / (‖a‖₂‖b‖₂)，判时换成 1 − cos | 最小 | 两边全零给 1；只有一边全零给 0 | 参数梯度 1 − cos ≤ 1.3e-7 |
| `norm_ratio` | ‖a‖₂ / ‖b‖₂，按 \|比值 − 1\| 判 | 偏离最大 | b 全零：a 也全零给 1，否则 inf | 参数梯度偏离 ≤ 4.6e-4；梯度 ×1/8 的演练偏离 0.875 |
| `std_ratio` | std(a) / std(b)，按 \|比值 − 1\| 判 | 偏离最大 | std(b) = 0：std(a) 也为 0 给 1，否则 inf | 参数梯度偏离 ≤ 4.6e-4 |
| `mean_shift` | \|mean(a) − mean(b)\| / std(b) | 最大 | std(b) = 0：均值相同给 0，否则 inf | 前向 0 |
| `zero_frac_diff` | 两边零元素占比之差的绝对值（±0 都算零） | 最大 | 空张量给 0 | 参数梯度 ≤ 2.4e-4 |
| `rel_err_p99` | \|aᵢ − bᵢ\| / max(\|aᵢ\|, \|bᵢ\|, eps) 的 99 分位，eps = 1e-3 × RMS(b) | 最大 | 两边都为 0 的元素给 0；空张量给 0 | 参数梯度 ≤ 4.4e-2 |
| `max_abs` | max\|aᵢ − bᵢ\| 及坐标 | 最大 | 空张量给 0、无坐标 | 更新后主权重 ≤ 1.8e-5 |
| `kl`（只用于 logits） | 每行 softmax 后 Σⱼ p_b(j)·(log p_b(j) − log p_a(j))，即 KL(参照 ‖ 被测)，取行平均 | 最大 | 见下 | GPU 自比 0；权重 ×(1+1e-2) 7.4e-5；开 dropout 0.196 奈特 |
| `out_of_tol_ratio` | \|aᵢ − bᵢ\| > atol + rtol·\|bᵢ\| 的元素比例 | 最大 | 空张量给 0 | 目录里暂未使用 |

### 噪声上限与判定

- 每一对噪声运行，按同样的选择规则选张量（名单从这一对的第一份运行里选）、算同一个指标，取这一对里最差的张量得到一个数；N = 所有对里的最大值。
- r = 被测这批里最差的值 ÷ N，判法同逐步序列。张量检查结果里的 `r1` 是各指标 r 的最大值，没有 `r2`。

### 几个指标的细节

- `rel_l2`：分子分母都随元素个数按 √N 增长，个数自动约掉。不除数值总和，正负抵消会接近 0。
- 大张量用 `pair_stats` 分块（每块 800 万元素转 FP64 累加）一遍算完 `rel_l2`、`cosine`、`mean_shift`、`max_abs`、`norm_ratio`，与逐个指标同定义；有非有限值时退回逐个指标。
- `rel_err_p99`：分母取两边绝对值较大者，对称。eps 取 1e-3 × RMS(b) 是推断，理由是比典型元素小三个数量级的元素在 rel_L2 里的权重已可忽略，不该主导逐元素分位数。报 p99 不报最大值，因为最大值总落在个别接近 0 的元素上。
- `kl`：方向是 KL(参照 ‖ 被测)，参照认为可能的 token 被测给低了才罚得重。FP64 按行 log-softmax，256 行一块。两边 −inf（被屏蔽的 token）位置必须一致，按概率 0 处理；参照概率 > 0 而被测为 −inf 给 inf；NaN 报错；两边逐位相同给 0。

## FP64 R 比：单算子、逐层前向与反向、整网输出

R = rel_L2(被测输出, FP64 真值) ÷ rel_L2(GPU 输出, FP64 真值)，≤ 1.2 过。

混元 4 有两个变体：TPU 自比的分母取 max(参照离 FP64, GPU 三份中位数)；GPU ↔ TPU 第 1 步有分辨率下限，GPU 噪声为 0、且两边离 FP64 都小于 u = 2^-8 的张量按下限判过（[尺子 2.3](../guide/ruler.md#23-两种用法)）。

- FP64 真值：用同一份真实输入、同一份 BF16 权重在 FP64 里算，全程不舍入。前向用 [`fp64_forward.py`](../../models/hunyuan3/analysis/fp64_forward.py)，反向用 [`fp64_backward.py`](../../models/hunyuan3/analysis/fp64_backward.py)，整步梯度用 [`fp64_step.py`](../../models/hunyuan3/analysis/fp64_step.py)。
- 两侧各用自己的输入，结果名带 `own`：被测对「被测输入上的真值」、GPU 对「GPU 输入上的真值」，上游差异不进来。
- 门槛 1.2 是推断：只差舍入顺序时 R ≈ 1；多一次同量级的独立舍入，误差方差约翻倍，R ≈ √2 ≈ 1.41。GPU 侧 `L1.rratio.clean`（R = 1.00）与 `L1.rratio.drill`（多舍一次，被 1.2 抓到）是这条线的自检。
- 一条检查选中几个观测点或几个张量时，取最差的 R。第 1 步整步梯度另报按梯度能量加权的整网 R（Σ‖被测 − FP64‖² ÷ Σ‖GPU − FP64‖² 开方）。
- 结果里另记被测对 GPU 的同名统计 `vs_ref_*`（只在两侧输入相同时有意义），给参考档用。

## 路由

| 指标 | 怎么算 |
|---|---|
| `set_frac` | 每个 token 选中的 top-k 专家集合相同的 token 数 ÷ token 总数（主判） |
| `order_frac` | 顺序也相同的比例 |
| `topk_margin` | 每行第 k 名与第 k+1 名的分差（FP64），说明翻转是不是「几乎打平被舍入翻过去」 |

- 对 FP64：本侧路由输入在 FP64 里算 logits、加偏置取 top-8，与本侧实际选中的比，门槛 0.97。
- 逐层回放的路由：门槛 1 − 1.2 × (1 − GPU 对 FP64 的 `set_frac`)，即被测的翻转率不超过 GPU 的 1.2 倍。
- 实测：GPU 第 1 步 3 个 MoE 层全部 1.0；两次 GPU 运行走到第 1000 步只剩 34%。这时权重已分叉，不可比，所以逐张量比较只在第 1 步做。

## 优化器重放

- 用读出的 FP32 主权重、梯度、实际生效的超参（学习率、权重衰减、裁剪系数），在 FP64 里重放一步 AdamW，比**更新量**的 rel_L2，门槛 5e-3。
- 不比更新后参数：参数比更新量大约三个数量级，比参数会把更新错藏进舍入里。
- 连续多步：第 k 步用第 k−1 步重放出的动量。学习率为 0 的一步参数不动，`optimizer_step` 直接报 error。
- 实测：GPU 单步 1.79e-3、连续 8 步 3.37e-3；v5p 单步 2.13e-3、连续 8 步 4.80e-3。

## 逐位、输入指纹与 ULP

| 指标 | 怎么算 |
|---|---|
| 逐位（`bitwise_equal`、`checkpoint_equal`） | 按原始字节比，BF16 就按 BF16 的 16 位；NaN 的位模式、−0.0 都算 |
| 输入指纹（`data_fingerprint`） | 每个「步 · rank · microbatch」的 tokens / labels / loss_mask / position_ids 各算 sha256 逐个比；另比每步全局非 padding token 数、首步 loss |
| `ulp_distance` | 两边必须是同一种原始浮点 dtype（BF16 按 BF16 数，按 FP32 数会放大 65536 倍）；位模式转成单调整数后相减，非有限值位置给 −1 |
| `ulp_summary` | 0 ULP 与 1 ULP 的比例、p50 / p99 / p99.9、最大值、分桶 0 / 1 / 2–4 / 5–8 / 9–16 / 17+；跨零元素单列，不进分位数与分桶 |

ULP 只诊断，不当门槛：跨芯片、经过长求和以后，健康的差也常有几格到几十格。GPU 两次运行第 1 步的梯度，差 1 格的只占 1.3%，17 格以上占 67%（`phase1-full` 的 `L3.step1.grads.ulp`）。

## 参考档的三个统计

只给参考档用，严格档不判（`reference_stats`）：

- 超差元素比例 `oot_frac` = \|aᵢ − bᵢ\| > 2⁻⁶·rms(b) + 2⁻⁶·\|bᵢ\| 的元素占比；
- 均值差 `mean_diff` = mean\|a − b\| / mean\|b\|；
- 归一化最大误差 `norm_max` = max\|a − b\| / max\|b\|。

外部实践没写容差，也没说均值差是绝对还是相对，这三处取法都是推断，理由在 [`reference_gates.yaml`](../../janus/report/reference_gates.yaml) 开头。超差比例对容差很敏感：v5p 第 3 层反向在这个容差下是 0.942%，贴着 1% 的线。

## 点积 / 归约误差归一

`normalized_dot_error(s_hat, s_ref, abs_sum)` = \|ŝ − s\| / Σ\|xᵢyᵢ\|，单算子回放用。

- ŝ 是被测的一次归约结果（如 GEMM 的一个输出元素），s 是同一组输入的 FP64 重算，abs_sum 是同一组输入的 Σ\|xᵢyᵢ\|（GEMM 时就是 \|X\| @ \|Y\|）。
- 按 Σ\|xᵢyᵢ\| 归一，是因为正负抵消会让 \|s\| 接近 0，按 \|s\| 归一的相对误差虚高。舍入误差的自然尺度是参与累加的各项绝对值之和，归一后只和累加顺序、累加精度有关；FP32 顺序累加的上界约 n·2⁻²⁴。
- 只能在拿到真实输入、自己算出 s 与 abs_sum 时用，不能用在两份算完的张量之间。目前还没有检查类型调用它。
- abs_sum = 0：差为 0 给 0，否则 inf；abs_sum < 0 报错。
