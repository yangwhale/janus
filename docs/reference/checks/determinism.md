# determinism

**用途**：基线可复现；观测（抓数钩子）不改数值。

**输入**：两次运行的标量序列 {字段: {步号: 值}}；可选张量对。`select.window`（`"a:b"`，可选）只比窗口内的步，例如日常回归的 R08 / R09 只比第 1 步（`"1:2"`）；被测在窗口内一步都没有 → `error`。

**判据**：每个字段逐步逐位相同，且张量逐字节相同 → `pass`；否则 `fail`，报第一处不同。只比被测有的那些步（短运行对长基线时不用写窗口）；参照缺被测有的步算不同。

**边界**：被测某个字段一步都没有（拼错、或这次运行没记）→ `error`，不判 `pass`。
